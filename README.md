# 4rtools

Ferramenta de automação para Ragnarok Online.

## Resposta ao enigma

> **"Chat qual cor eu tiro 4 letras e fica 5?"**

A resposta é **VERDE**:

- VERDE possui 5 letras: **V** · E · R · D · E
- Tirando as 4 letras (E, R, D, E), fica apenas o **V**
- **V** é o algarismo romano que representa o número **5**
